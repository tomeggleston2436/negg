# negg-calib

Rig profiles: flat field, crosstalk and the camera-to-density fit.

## Owns

- Rig profile data structures
- Flat-field correction and crosstalk estimation
- The camera-to-density fit

## Must not

- Decode RAW or TIFF files
- Do any file I/O
- Perform per-pixel rendering of final images
