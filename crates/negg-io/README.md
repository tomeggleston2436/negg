# negg-io

TIFF, DNG and JPEG writers plus sidecar files.

## Owns

- TIFF, DNG and JPEG output writers
- Sidecar files for settings and metadata

## Must not

- Decode input files
- Contain rendering or colour maths
- Depend on the CLI or app
