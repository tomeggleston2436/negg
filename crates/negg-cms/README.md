# negg-cms

Colour management: working space, ICC profiles and soft proof.

## Owns

- The working colour space definition
- ICC profile loading and transforms (via lcms2)
- Soft proofing

## Must not

- Decode or invert images
- Write output files
- Contain film or rig calibration maths
